1平均に合わせることが目的ではありません

POINT

総務省の家計調査は、世帯がひと月に何にいくら使っているかを調べた統計です。自分の家計を眺めるときの「ものさし」として使えます。ただし、平均に合わせることが目的ではありません。差があるところに理由があるかどうかを見る、という使い方になります。そして、そもそも比べられない費目が3つあります。

この記事でわかること
  1. 平均より多い＝使いすぎ、ではありません
  2. 比べられない費目が3つあります
  3. 見るのは差があるところに理由があるかです

2どんな数字？

1か月の消費支出の平均
「住居」の平均ローン返済を含みません
「教育」の平均
生命保険料の扱い消費支出の外にあります

大きな区分は10種類です。食料、住居、光熱・水道、家具・家事用品、被服及び履物、保健医療、交通・通信、教育、教養娯楽、その他の消費支出。

世帯人数や年齢によって平均は変わります。比べるときは、近い区分を選ぶことになります。

3気をつける費目が、3つあります

「住居」には、住宅ローンの返済が入っていません持ち家でローンを返している人の住居費とは、意味が違います。そのまま比べられません。
「交通・通信」に、自動車の維持費と購入費が入っています車を持っているかどうかで、大きく動く区分です。
生命保険料は、そもそも消費支出の外にあります家計調査の消費支出には含まれないため、比べる相手がありません。
このサイトでは、比べられない費目をはっきり分けています並べられないものを無理に並べると、読み間違いのもとになります。比べられない費目は、その理由とともに「比較対象外」と表示しています。

4よくある勘違い

平均より多い＝使いすぎ住んでいる地域、家族構成、働き方によって、必要な金額は変わります。通信費が多いのは在宅勤務のため、ということもあります。
平均より少ない＝うまくやれている必要な支出を削っている場合もあります。
平均は「真ん中の人」の金額平均値は、一部の大きな支出に引っ張られることがあります。
どの費目も平均と比べられる統計の分け方と、自分の感覚の分け方は一致しません。比べられない費目があります。

5このサイトの計算では、どう使っているか

結果画面で、入力された支出の内訳を世帯の人数が近い区分の平均と並べて表示しています。多い・少ないを示すだけで、良い・悪いの判断はしません。比べられない費目は、その理由とともに「比較対象外」と表示します。

6もっと正確に知るには

家計調査は毎年公表され、世帯人数別・年齢別・地域別の集計も公開されています。下の出典から、自分に近い区分を探せます。
